# Milestone 7 plan — value model + non-greedy search leaf

Branch: `m7-value-model` (from `main` at `m6-accepted`).

## Context

Design-doc Building Block 6 (`docs/design.md:378`) and the m7 exit row (`docs/design.md:530`) call for a learned value model that scores a seat-relative observation and is called from the Rust search as a rollout-leaf evaluator, with the exit test *equal strength at lower cost per decision, or higher strength at equal cost*.

Milestone 6 accepted on 2026-11-28 (tag `m6-accepted`, commit `77c8171`). The m6 result pinned down what m7 must do:

- D50 showed `CleanSplitCloseWrapper<RuleBased>` beats rule-based at 57.3% but lands statistically 50/50 vs score-aware. The close-card picker captures essentially the full score-aware edge, so the equity-table-only evaluator is near its ceiling at Close decisions. **Non-Close decisions (Draw, Discard) are where a learned value head should pay for itself.**
- D37 deferred the m4 "search beats rule-based" exit test to m7 because PIMC-with-greedy-rollouts cannot beat greedy (structural strategy fusion). m7 both discharges that regression and delivers the design-doc m7 exit test.

Three CLAUDE.md checks pass on `main` as of planning time: fmt clean, clippy 0 warnings, `cargo test --workspace` green.

## Decisions settled (logged as D51–D57 in `docs/decisions.md`)

- **D51 Training stack.** Python trains (PyTorch); Rust infers via a hand-written forward pass over JSON weights. Rust↔Python boundary is a Rust CLI emitting a binary dataset file + a Python training script reading it; no `pyo3` yet. Compute path: data generation is `rayon`-parallel across matches (D43 precedent); training is CPU-only (model ≈50 k params, dataset ≈300–500 k samples — finishes in a few minutes on a laptop CPU, GPU overkill at this scale); committed-weights run pins `torch.set_num_threads(1)` + seeds for byte-identical reproducibility.
- **D52 Network.** Value-only MLP: input 261, two hidden layers × 128 ReLU, one sigmoid scalar output. ≈50 k parameters, <1 MB JSON weights.
- **D53 Input encoding.** Fixed-size seat-relative layout, 261 f32. Same shape for 2 to 4 players (absent seat slots zero-masked). Layout: own-hand bitmask (40) + top-discard one-hot (40) + cards-seen bitmask (40) + per-seat scores ÷ 100 (4) + per-seat hand-sizes ÷ 10 (4) + per-opponent known_held bitmasks (3 × 40 = 120) + phase one-hot (3) + turn_number ÷ 30 (1) + stock_size ÷ 40 (1) + seat-present mask (4) + current-seat one-hot, seat-relative (4). `pub const ENCODING_SIZE: usize = 261;` + `pub const ENCODING_VERSION: u32 = 1;`. Seat ordering: slot 0 = `own_seat`, slot i = `Seat((own_seat + i) mod N)`.
- **D54 Dataset + label.** Supervised. ≈2 k matches of `score-aware` vs `score-aware` + ≈2 k of `clean-split-close` vs `clean-split-close` (seeded, paired). Record every Draw/Discard decision's encoded observation. Label = `committed_table().lookup(own_score_at_end_of_this_hand, opp_score_at_end_of_this_hand)`. MSE loss. Showdown decisions excluded.
- **D55 Search integration.** Rollout-leaf with depth-D cutoff. Add `LeafEvaluator { Greedy | ValueModel(Arc<ValueModel>) }` enum to `SearchPlayer`; `Greedy` is the existing behaviour plus an equity-unit conversion so both leaves return equity ∈ [0, 1]. Default `leaf_depth = 3`. Keep greedy-leaf behind a flag for A/B. Showdown-mid-rollout falls back to the existing greedy showdown policy to a true terminal, then equity-convert.
- **D56 Exit bar.** Gate 1 (D37 discharge): `search+value` beats `RuleBased` with Wilson LB > 0.5 at 1000 paired deals (`#[ignore]`d regression). Gate 2 (design-doc target, at K=50, D=3): beats both `ScoreAware` and `CleanSplitClose` with Wilson LB > 0.5 at 500+ paired deals, OR matches their win rate at K=10 (equal strength, lower cost). Cost metric per agent: decisions/sec, rollouts/decision, neural-evals/decision. Partial-pass (only gate 1) is allowed.
- **D57 Disk layout.** Weights: `crates/conga-ai/assets/value_model_v1.json`. Training: `training/` at repo root (outside Cargo). Dataset file: `data/value_model_v1_samples.bin`, not committed (`/data/` in `.gitignore`).

### Slice 1 — `conga-ai::encoding` module

Goal. Deterministic `encode(obs, belief) -> [f32; 261]` with a seat-relative permutation layer.

Files.
- `crates/conga-ai/src/encoding.rs` (new). Public: `ENCODING_SIZE`, `ENCODING_VERSION`, `pub fn encode(obs: &Observation, belief: &BeliefTracker) -> [f32; ENCODING_SIZE]`.
- `crates/conga-ai/src/lib.rs` — `pub mod encoding;` and re-export the two consts.

Mechanics.
- Seat ordering: slot 0 = `own_seat`; slot i = `Seat::new((own_seat.index() + i) % hand_sizes.len())`.
- Cards-seen bitmask = `own_hand ∪ discard_history ∪ cards_in_melds_on_table ∪ Σ belief.known_held(opp_seat)`.
- Phase one-hot: `Draw = [1,0,0]`, `Discard = [0,1,0]`, `Showdown = [0,0,1]`. Debug-assert `Phase::Ended` doesn't reach here.
- Normalisations: scores `/ 100.0`, hand_sizes `/ 10.0`, turn_number `/ 30.0`, stock_size `/ 40.0`. Accept out-of-range without clipping.

Tests (inline `#[cfg(test)]`).
- `encoding_size_is_261`.
- `own_hand_bits_set` — put 7 known cards in `own_hand`, verify exactly those 7 bits in slots 0..40 are 1.
- `top_discard_one_hot` — `None` yields all zeros in slots 40..80; a given `Card` sets exactly one bit.
- `seat_relative_cyclic_invariance` — build a State mid-hand, encode from each of the 2 seats' observations; after cyclically rotating the per-seat blocks of the second encoding by `−1`, the two must be bit-identical.
- `absent_seat_slots_are_zero` — a 2-player observation zeros the slots for seats 2 and 3.
- `phase_one_hot_sums_to_one`.
- `cards_seen_union` — fixture: `own_hand = {1C,2C}`, `discard_history = [3C]`, one opp `known_held = {4C}`; assert bits 0..4 set in the cards-seen block.
- `encoding_snapshot_fixture` — pin every byte of one known observation's encoding.

Check. Three CLAUDE.md commands.

Try it. Verified by tests; no CLI yet.

### Slice 3 — Rollout-leaf integration + end-to-end minimal with toy weights

Goal. `SearchPlayer` can use a `ValueModel` as a rollout-leaf evaluator at depth D. Verify the integration end-to-end with a fixture-built toy model, before any training.

Files.
- `crates/conga-ai/src/search.rs` — add:
  - `pub enum LeafEvaluator { Greedy, ValueModel(Arc<ValueModel>) }` (default `Greedy`).
  - `SearchPlayer { ..., leaf_evaluator: LeafEvaluator, leaf_depth: u32 }` (default `leaf_depth = 3`).
  - Builders: `.with_leaf_evaluator(..)`, `.with_leaf_depth(..)`.
  - Rollout loop refactor (equity units throughout):
    1. On terminal: return `committed_table().lookup(own_total, opp_total)`.
    2. At `ply == leaf_depth` with `ValueModel(m)`: build leaf obs via `self.rules.observe(state, own_seat)`, call `encode(&leaf_obs, &leaf_belief)`, return `m.forward(&x)`.
    3. On Showdown-mid-rollout: continue with the existing greedy showdown policy to a true terminal, then equity-convert.
    4. `Greedy` leaf: existing full-rollout behaviour, terminal converted via `committed_table().lookup(..)`.
  - Retain `opp_weight` as a field; documented no-op in the value-model path.
- `crates/conga-ai/src/eval.rs` — add `BaselineAgent::ValueSearch(Box<SearchPlayer>)` and `from_name("value-search")`. For slice 3, point the dispatcher at a test-fixture toy model; slice 5 switches it to `committed_v1()`.
- `crates/conga-cli/src/main.rs` — register `"value-search"` in the `--ai` value_parser lists.
- `crates/conga-ai/src/belief.rs` — if needed, add a thin `from_observation` helper to rebuild a belief on a sampled-leaf observation. Verify at slice start; skip if the existing API suffices.

Mechanics.
- Toy model built in a `tests::toy_equity_proxy_model()` fixture returning a `ValueModel` whose forward output approximates `sigmoid(opp_dist_to_elim − own_dist_to_elim)`. Not committed as JSON.
- `leaf_depth = 0` degenerates to a one-ply evaluator.

Tests.
- `leaf_evaluator_default_is_greedy`.
- `value_leaf_depth_zero_evaluates_root_action` — hand-coded model returns 1.0 for one action and 0.0 for others; assert `act` picks the 1.0 action.
- `rollout_short_circuit_on_terminal` — position one draw from close; returns equity from `committed_table()`, not the model.
- `showdown_midflight_falls_back_to_greedy` — rollout entering Showdown pre-depth returns equity in [0, 1] without calling `ValueModel::forward` (verified via a counting proxy).
- `value_search_beats_random` — 20 paired matches with the toy model, win rate > 70%.
- `encoding_round_trip_at_leaf`.

### Slice 4 — Self-play labelling CLI

Goal. Emit a labelled dataset from paired self-play of the current ladder in a format the Python trainer can read efficiently.

Files.
- `crates/conga-ai/src/dataset.rs` (new). Public: `Sample { encoding: [f32; ENCODING_SIZE], label: f32 }`, `write_binary(path, samples)`, `generate(matches_each, seed) -> Vec<Sample>`.
- `crates/conga-cli/src/main.rs` — new subcommand `self-play-batch --matches-each <N> --seed <S> --out <path>`.

Binary format: 8-byte magic `b"CONGADS1"`, LE `u32` `ENCODING_VERSION`, LE `u32` `input_size`, LE `u64` `num_samples`, then `num_samples × (input_size + 1) × f32` little-endian rows (encoding first, then label).

Mechanics.
- Reuse existing `conga-ai::eval` paired-deal plumbing. Fork a `BeliefTracker` per acting seat; keep it in sync with the authoritative event stream so `encode` sees the same belief the agent would.
- Parallelism: `rayon`-parallel across matches (reuse D43 precedent). Each worker runs independent paired deals and buffers samples locally; the main thread concatenates and writes the binary file. Expect ≈35 min wall-clock for 2 × 2000 matches on 12 cores (serial would be ≈7 h at m5-era score-aware speed).
- Label each sample taken during hand H with `committed_table().lookup(own_final_H, opp_final_H)` (seat-relative to the sample's acting seat).
- Omit Showdown-phase decisions.

Tests.
- `write_read_roundtrip` — write 10 samples, read back via a Rust reader, compare bytes.
- `generate_smoke` — small run returns finite labels in [0, 1].
- `generate_deterministic` — same seed → byte-identical.
- `showdown_decisions_excluded`.

## Risks and fallbacks

- **Gate 2 misses because rollouts remain greedy-driven.** The plan agent flagged that D37's "strategy fusion" argument is about the whole-rollout policy, not just the terminal. Fallback: add `RolloutPolicy::ScoreAware` / `RolloutPolicy::ValueModelOneStep` as cheap enum arms.
- **Dataset too big for JSONL.** Pre-mitigated by the binary format in slice 4.
- **High Showdown-mid-rollout rate reduces leaf coverage.** Slice 3 instruments the rate; if > 50% we re-weight training samples toward late positions.
- **Committed v1 weights not reproducible across machines.** Slice 5 verifies byte-identical output via `smoke_reproduce.sh`. Adds a `.safetensors`-style hash if it fails first run.
- **Supervised label ceiling.** The value head's accuracy is bounded by the trajectory-generating policies. Documented as a known limitation; m8 can retrain on `search+value` trajectories (bootstrapping).
