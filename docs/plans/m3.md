# Milestone 3: baseline agents + evaluation harness

## Context

Milestone 2 is accepted (`m2-accepted` on `main`). The engine, the pluggable `RuleSet`, the authoritative server, the TUI and a seeded `RandomPlayer` all exist with 220 tests green; `GameLog` + `replay` reproduce whole matches.

Milestone 3 fills `conga-ai` with two stronger baselines and a headless evaluation harness. The design-doc exit test is: *Random loses to greedy and greedy loses to rule-based, each outside the confidence interval. Rollouts per second measured.* Rollouts per second is reinterpreted as "decisions per second" for this milestone (see D30); the rollouts figure lights up in m4 when the search agent arrives.

Nothing in m3 needs the TUI, WebSocket, rayon or new workspace deps.

## Decisions taken in planning

| # | Date | Decision | Reason |
| --- | --- | --- | --- |
| D26 | 2026-11-18 | `Player::act` becomes synchronous: `fn act(&mut self, obs: &Observation, legal: &[Action]) -> Action`. The m2 `run_player` driver still runs under tokio for transport IO; the trait method is called sync inside the `AwaitAction` branch | Current impl wraps pure CPU work in `impl Future<Output = Action>`, which costs nothing and reads worse. Sync is forward-compatible with rayon when parallel eval lands, and nothing outside `conga-ai` depends on the async signature |
| D27 | 2026-11-18 | Greedy agent definition: draw whichever source reduces the solver's unmatched total more (tie: stock). Always lay a legal meld or add to a meld if available. Discard the highest-rank unmatched card (ties broken by card index). Close whenever `can_close`. Pass only when no other action is legal. Deterministic (no RNG) | Smallest heuristic that ought to beat Random cleanly. Deterministic means eval runs are reproducible from the match seed alone |
| D28 | 2026-11-18 | Rule-based agent = greedy + discard safety. Safety signal v1: score each legal discard by whether it fits any meld the next seat is visibly building (their `melds_on_table`) or completes a run with a card they recently took from the discard. Among discards tied on greedy value, pick the safest; if nothing is safe, fall back to greedy. State per turn only; no cross-match memory in m3 | Simplest signal strong enough to beat greedy. Opponent-hand modelling (belief tracker) is m4's business; keeping m3 state-free avoids contaminating the two layers |
| D29 | 2026-11-18 | Eval harness is headless and bypasses the m2 server: calls `rules.legal_actions` → `agent.act` → `rules.apply` directly against the m1 engine. Duplicate deals: each paired game runs the same `Chance` seed twice with A/B on swapped seats. Single-threaded in m3; rayon deferred | Faster, fewer moving parts. The server's async transport layer serves live play, not batch simulation |
| D30 | 2026-11-18 | The design-doc m3 exit test's "rollouts per second" metric is recorded as "decisions per second" in m3 because baseline agents do not do rollouts. The rollouts figure returns in m4 with the search agent | Baseline agents choose deterministically from a legal set; there is no rollout to measure. "Decisions per second" measures the same thing the design doc's intent cared about: how fast eval can run |

These five rows are appended to `docs/decisions.md` in the same commit that saves this plan.

## Known facts I rely on

- `conga-rules::StandardConga` + `Chance` deliver reproducible shuffles from a seed (m1 slices 2–8).
- `conga-core::evaluate_hand` returns the unmatched total and `can_close`. Greedy needs nothing more than this plus `legal_actions`.
- Rule-16 tie-break and rule-12 elimination are already in `StandardConga`, so the harness loops until `MatchStatus != InProgress` without extra rule logic.
- `MatchState` in `conga-server` already handles dealer rotation + match-level scoring; the headless runner copies its shape rather than depending on the async server.
- Wilson score interval is the CI of choice. Robust at extreme win rates; no z-table surprises.

## API verifications before each slice

No new crates in m3, so no docs.rs checks are needed. The one shape change is the `Player` trait signature (D26), which is a local trait.

## Slices

Each slice is on branch `m3-baselines-eval`, ends with the three CLAUDE.md checks green, ends with a stop report. One slice at a time.

### Slice 1 — `Player` trait becomes sync

**Files**: `crates/conga-ai/src/{player,random,driver}.rs`; `crates/conga-ai/tests/random_player.rs`.

**Content**: drop the `impl Future<Output = Action>` return from `Player::act`. `RandomPlayer::act` returns `Action` directly. `run_player` calls `player.act(...)` synchronously inside the `AwaitAction` branch; everything else stays. `notify(&event)` stays default.

**Tests**: existing `RandomPlayer` tests (uniform distribution, legal-action picks) pass with the sync signature. The driver test that walks `AwaitAction` → `Act` stays green.

**Dependencies added**: none.

### Slice 2 — `GreedyPlayer`

**Files**: `crates/conga-ai/src/greedy.rs`; `crates/conga-ai/src/lib.rs`; `crates/conga-ai/tests/greedy.rs`.

**Content**: `GreedyPlayer` implementing `Player`, no state across turns. Uses `evaluate_hand` for `unmatched_total` and `can_close`. Deterministic ordering (see D27).

**Tests**:
- On a hand that can close, `act` returns the `Close` action.
- Prefers a legal `LayMeld` over a plain `Discard` when both are offered (laying always reduces hand size).
- Given both draw options, picks the one that lowers unmatched total more; tie goes to stock.
- Discard choice is the highest-rank unmatched card.
- `Pass` only when no other action is legal.

**Dependencies added**: none.

### Slice 3 — `RuleBasedPlayer`

**Files**: `crates/conga-ai/src/rule_based.rs`; `crates/conga-ai/src/lib.rs`; `crates/conga-ai/tests/rule_based.rs`.

**Content**: builds on greedy (D28). Discard-safety v1 scores legal discards against the next seat's observable meld-building. Among discards tied on greedy value, picks the safest. Per-turn state only.

**Tests**:
- Given two equally-high discards, prefers the one the next seat cannot trivially use.
- When the next seat has `[7♣ 7♦]` on the table, refuses to discard `7♥` unless no other discard is legal.
- Mirrors greedy when the safety signal is silent.

**Dependencies added**: none.

### Slice 4 — Headless match runner + duplicate deals

**Files**: `crates/conga-ai/src/eval/{mod,runner,outcome}.rs`; `crates/conga-ai/tests/eval_runner.rs`.

**Content**:
- `run_match<R, A, B>(rules, a, b, starting_dealer, seed) -> MatchOutcome` plays a full match head-to-head using the engine directly.
- `run_paired(rules, builder_a, builder_b, seed) -> [MatchOutcome; 2]` runs the same `Chance` seed twice with seats swapped.
- `run_batch(builder_a, builder_b, games, start_seed) -> Vec<MatchOutcome>` aggregates `games/2` paired runs (`games` rounded to an even number).
- `MatchOutcome { winner: Option<Seat>, final_scores: Vec<i32>, hands_played: u32, decisions: u64 }`.

**Tests**:
- A 10-match batch of `RandomPlayer` vs `RandomPlayer` produces a winner for each match (or a draw if rule-16 fires).
- `(builder_a, builder_b, seed)` reproduces the exact same `Vec<MatchOutcome>` across calls.
- Paired deal: same `Chance` stream, different outcomes (because the acting player differs on each seat).

**Dependencies added**: none.

### Slice 5 — `EvalReport` + Wilson CI + `conga-cli eval`

**Files**: `crates/conga-ai/src/eval/{report,stats}.rs`; `crates/conga-cli/src/eval.rs`; `crates/conga-cli/src/{main,lib}.rs` updated.

**Content**:
- `EvalReport { games, a_wins, b_wins, draws, mean_a_score, mean_b_score, hands_per_match, duration_ms, decisions_per_second }`.
- `wilson_ci(wins, n, z=1.96) -> (lo, hi)`.
- New CLI: `conga-cli eval --a <agent> --b <agent> --games <N> --seed <u64>` where agent names are `random | greedy | rule-based`. Prints a short human-readable report.

**Tests**:
- `wilson_ci(50, 100)` returns roughly `(0.40, 0.60)`.
- `wilson_ci(100, 100)` upper bound is 1.0, lower bound is strictly less than 1.0 (does not blow up).
- `conga-cli eval --a random --b random --games 20 --seed 1` runs, exits 0, prints a win-count line.
- Smoke: `--a greedy --b random --games 200 --seed 1` has greedy's win-rate lower CI bound above 0.5. (Regression test in slice 6; this one is a quick signal.)

**Dependencies added**: none.

### Slice 6 — Exit-test regression + decisions/sec measurement

**Files**: `crates/conga-ai/tests/exit_regressions.rs`.

**Content**: two integration tests, deterministic. Each plays enough matches (2000 should be safe) that the 95% Wilson CI margin is comfortable: greedy ~70% against random, rule-based ~60% against greedy, both well outside the CI. The tests also assert `decisions_per_second > 0` so the metric is wired.

**Tests**:
- `greedy_beats_random`: 2000-game eval with seed `0xC0FFEE`; `wilson_ci(greedy_wins, games).0 > 0.5`.
- `rule_based_beats_greedy`: 2000-game eval with a different seed; same lower-bound assertion.

**Dependencies added**: none.
