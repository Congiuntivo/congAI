# Milestone 4: belief tracker and search agent

## Context

Milestones 1, 2 and 3 are accepted (tags `m1-accepted`, `m2-accepted`, `m3-accepted` on `main`). The core engine, the `RuleSet` trait, `StandardConga`, the game server, the protocol, the TUI, three baseline agents (`RandomPlayer`, `GreedyPlayer`, `RuleBasedPlayer`), the headless eval harness with Wilson CI and the stalemate terminal (C4, D31) are all in. 261 tests pass (263 with `--ignored`). Rule clarifications C1-C4 are encoded. Decisions D1-D31 are logged.

The m3 rule-based agent (D28) underperforms greedy at 36-38% in three seed smokes. The failure cause is not information: its ad-hoc pickup tracker is only a proxy for "what the opponent needs," and the discard-safety heuristic actively biases the agent to hold heavy cards. Milestone 4 replaces both the information layer (with a proper belief tracker) and gives the rule-based agent one conditional slice to redeem itself.

Milestone 4 delivers:
- `StandardConga::sample_state`, filling in the trait method that has panicked since m1, and conformance test 5 ("every sampled state reproduces the observation it was sampled from").
- A `BeliefTracker` in `conga-ai` that watches events and samples opponent hands consistent with the observation history.
- A `SearchPlayer` running PIMC (flat determinized rollouts with shared determinization), using the belief tracker for samples and `GreedyPlayer` as the rollout policy. **Shipped as scaffolding only (D37): the standalone search agent returns in m7 with the learned value model.**
- `conga-cli eval` and `conga-cli play` both learn `search` (and optional `rule-based-v2`) as agent names.
- A re-attempt at rule-based v2 using the belief tracker. Conditional ship: the slice merges only if v2 beats greedy with Wilson LB > 0.5 over 1000 paired deals. If not, the slice is reverted.
- Headless exit regressions (#[ignore]d in debug, runnable in release): **rule-based v2 beats greedy** (the m4 exit gate, replacing the deferred "search beats rule-based"); rule-based v2 beats random.

The exit test proves the belief tracker's value: it enables a rule-based agent to beat greedy (which the D28 stateless version could not). Milestone 5 (match equity + score-aware play) then layers multi-hand reasoning on top; milestone 7 (value model) resurrects the standalone search by giving it a non-greedy leaf.

### Pivot (2026-11-20)

Slice 3 shipped SearchPlayer as a working Player (beats random 100-0 at K=20 over 50 games) but three diagnostic evals showed it cannot beat greedy:

| config | vs greedy | notes |
|--------|-----------|-------|
| default K=50 greedy rollouts | 4% (2/50) | strategy fusion: rollout policy > root policy |
| K=20 random rollouts | 0% (0/40) | variance drowns signal |
| K=20 opp_weight 0.3 | 12.5% (5/40) | shaping helps marginally, not enough |

Root cause (D37): PIMC's greedy rollout policy is strictly stronger than the search's actual root play. Value estimates are calibrated for a "greedy future" trajectory but the real game has search playing search. No value-function tuning fixes this — it needs a non-greedy rollout leaf, which is m7's learned value model.

Slice 4 is unchanged (rule-based v2). Slice 5's exit tests are reshaped to drop the `search_beats_*` assertions and ship the `rule_based_v2_beats_*` ones. Milestone framing becomes "belief tracker enables rule-based v2 to beat greedy; search ships as scaffolding."

## Known facts I rely on

From `docs/design.md`:
- Architecture (lines 109-176) places "Belief tracker, search, value model, explanations" inside `conga-ai`; no separate `conga-belief` or `conga-search` crate.
- Design rule 2 (line 196): one `observe(state, seat)` function is the only point hidden information is filtered. sample_state is its inverse.
- Design rule 3 (line 197): a game is stored as ruleset id, shuffles and action list, so replay stays deterministic even with search running.
- Design rule 5 (line 199): `act` is async in the Python sketch, but D26 made the Rust `Player::act` synchronous; the m2 driver still runs async transport around it.
- "Simulation speed" (lines 401-403): `rollouts per second` is the critical metric, with a sample-budget sketch of "100 samples × 8 legal × 1 rollout."
- Conformance test 5 (line 274): "Every sampled state reproduces the observation it was sampled from."

- `Observation` (`crates/conga-core/src/observation.rs:15-38`) carries `own_seat`, `current_seat`, `phase`, `own_hand`, `top_discard`, `discard_history`, `stock_size`, `melds_on_table`, `scores`, `hand_sizes`.

- `conga-ai/Cargo.toml` depends on `conga-core`, `conga-protocol`, `conga-server`, `rand_chacha`, `rand_core`. No cycle risk for in-crate belief + search modules.

### Slice 1 - `StandardConga::sample_state` + conformance test 5

**Files**:
- `crates/conga-rules/src/standard.rs` (replace the `unimplemented!()` body).
- `crates/conga-core/src/conformance.rs` (add `run_sample_state_checks` generic function).
- `crates/conga-rules/tests/sample_state.rs` (new).
- `docs/decisions.md` (D32-D36 appended).

**Content**:
- Implement `StandardConga::sample_state(&self, obs: &Observation, rng: &mut dyn Rng) -> State`:
  - Compute `seen = own_hand ∪ discard_pile ∪ cards_on_table`. The discard pile is reconstructed from `obs.discard_history` (position 0 = bottom, `obs.top_discard` = top); `obs.top_discard` may differ from `discard_history.last()` only after a recent `Drew{TopDiscard}`, in which case use `discard_history` as the authoritative set.
  - Compute `unseen = DeckSpec::standard_40 - seen`. Assert `unseen.len() == obs.stock_size + sum(obs.hand_sizes) - obs.own_hand.size()`.
  - For each opponent seat in deal order, draw `obs.hand_sizes[seat]` cards uniformly from `unseen`, remove them from `unseen`. Fill `state.hands[opponent]` with the result.
  - Shuffle `unseen` and set `state.stock = unseen` (top of stock is last, matching the engine convention).
  - Rebuild remaining State fields: `seats_count`, `scores`, `phase = Playing`, `current_seat`, `melds_on_table`, `first_turn_done = [true; seats_count]` (we're mid-hand), `must_not_discard = None`, `closer = None`, `closer_hand_at_close = None`, `closer_has_opened = false`, `showdown_consecutive_passes = 0`, `face_down_close = None`, `reshuffles_this_hand = 0`, `stalemate_pending = false`, `dealer` = `(obs.current_seat - 1) mod seats_count` as a reasonable default (exact value unrecoverable from observation; dealer doesn't affect subsequent legal_actions).
  - If `obs.phase == Phase::Showdown`, return an error or panic with a clear message: v1 of sample_state covers `Playing` only. Search agent handles this by falling back to greedy in showdown.
- Add `pub fn run_sample_state_checks<R: RuleSet>(rules: &R, seeds: &[u64], games_per_seed: u32, samples_per_turn: u32)` in `conformance.rs`:
  - For each seed, play `games_per_seed` random games (two RandomPlayers). At every Playing-phase turn, for each seat draw `samples_per_turn` sampled states via `rules.sample_state(obs, rng)` and assert `rules.observe(&sample, seat) == obs`.
  - Called from a new `#[ignore]`d integration test in `conga-rules/tests/sample_state.rs` against `StandardConga` (500 random hands × 20 samples/turn).

**Tests**:
- Unit (in `conga-rules/src/standard.rs` tests module): three hand-crafted observations (start of hand, mid-playing, just after a TopDiscard draw). For each, assert `observe(sample, own_seat) == obs` and that each opponent hand has the right size and disjoint cards.
- Unit: sample_state in `Phase::Showdown` panics with a clear message.
- Integration (`tests/sample_state.rs`, `#[ignore]`d): 500 hands × 20 samples/turn conformance check.

### Slice 2 - `BeliefTracker` module

**Files**:
- `crates/conga-ai/src/belief.rs` (new).
- `crates/conga-ai/src/lib.rs` (`pub mod belief; pub use belief::BeliefTracker;`).
- `crates/conga-ai/tests/belief.rs` (new).

**Content**:
- `pub struct BeliefTracker { own_seat: Seat, seats_count: u8, known_held: HashMap<Seat, HashSet<Card>>, last_discarded: Option<Card> }`.
- `BeliefTracker::new(own_seat: Seat, seats_count: u8) -> Self` initialises empty maps.
- `BeliefTracker::notify(&mut self, event: &Event)`:
  - `Discarded { seat, card }`: `self.last_discarded = Some(card)`. Also `known_held[seat].remove(&card)` (they just put it on the table).
  - `Drew { seat, source: TopDiscard }`: if `self.last_discarded` is Some, insert that card into `known_held[seat]`. Clear `last_discarded`.
  - `Drew { .., source: Stock }`: no info.
  - `LaidMeld { seat, meld }`: `known_held[seat]` loses `meld.cards`.
  - `AddedToMeld { seat, card, .. }`: `known_held[seat].remove(&card)`.
  - `HandEnded(..)`: clear everything.
  - Other events: no change.
- `BeliefTracker::known_held(&self, seat: Seat) -> &HashSet<Card>` for consumers (rule-based v2).
- `BeliefTracker::prob_holds(&self, card: Card, seat: Seat, obs: &Observation) -> f64`: 1.0 if in `known_held[seat]`; 0.0 if `card ∈ seen`; else `obs.hand_sizes[seat] / unseen_count`. Used by rule-based v2.
- `BeliefTracker::sample_state(&self, rng: &mut dyn Rng, obs: &Observation, rules: &StandardConga) -> State`: like `StandardConga::sample_state` but hands each opponent their `known_held` cards first, then samples the remainder from `unseen - all_known_held - own_hand`. Falls back to `rules.sample_state` when `known_held` is empty for every opponent.

**Tests**:
- Unit: `notify(Discarded{seat=0, card=7C})` then `notify(Drew{seat=1, source=TopDiscard})` ⇒ `known_held[seat=1]` contains `7C`.
- Unit: continuing, `notify(Discarded{seat=1, card=7C})` ⇒ `known_held[seat=1]` no longer contains `7C`.
- Unit: `notify(LaidMeld{seat=1, meld})` ⇒ `known_held[seat=1]` loses the meld cards.
- Unit: `notify(HandEnded(..))` clears all state.
- Unit: `sample_state` consistency: build a BeliefTracker by feeding a hand-written event sequence, sample 20 states, assert every opponent sampled hand is a superset of `known_held[opponent]`.
- Integration (`tests/belief.rs`, #[ignore]d): run 200 hands with two RandomPlayers while feeding a `BeliefTracker` for seat 0; at every turn, draw 20 sampled states and assert (a) `rules.observe(sample, seat=0) == obs`, (b) opponent sampled hand ⊇ `known_held[opponent]`.

**Dependencies added**: none.

**Try it**: `cargo test -p conga-ai belief` (unit tests ~instant; integration via `--release -- --ignored`).

**Files**:

- `crates/conga-cli/src/play.rs` (route the chosen opponent agent instead of hardcoding RandomPlayer).

**Content**:
- `pub struct SearchPlayer { rules: StandardConga, belief: BeliefTracker, rollout_policy_a: GreedyPlayer, rollout_policy_b: GreedyPlayer, rng: ChaCha8Rng, samples: u32 }`.
- `SearchPlayer::new(rules, own_seat, seats_count, samples, seed) -> Self`.
- `impl Player for SearchPlayer`:
  - `notify(event)`: forward to `self.belief.notify(event)`.
  - `act(obs, legal) -> Action`:
    - Fast path: if `legal.len() == 1`, return `legal[0]`.
    - Fast path: if `obs.phase == Phase::Showdown`, return `GreedyPlayer::default().act(obs, legal)` (no search in showdown, per D34).
    - Initialize `values: Vec<f64>` of length `legal.len()` to zero and `counts: Vec<u32>` to zero.
    - For `k in 0..self.samples`:
      - `sample = self.belief.sample_state(&mut self.rng, obs, &self.rules)`.
      - For `(i, a) in legal.iter().enumerate()`:
        - `sim = sample.clone()`.
        - `sim_chance = RandomChance::new(ChaCha8Rng::seed_from_u64(self.rng.next_u64()))`.
        - `self.rules.apply(&mut sim, *a, &mut sim_chance, &mut events_buf)`.
        - `rollout_value = rollout(&self.rules, sim, obs.own_seat, &mut self.rollout_policy_a, &mut self.rollout_policy_b, &mut sim_chance)`.
        - `values[i] += rollout_value; counts[i] += 1`.
    - Return `legal[argmax(values[i] / counts[i])]`.
  - `rollout(rules, state, own_seat, policy_a, policy_b, chance) -> f64`: loop apply → hand_result. On terminal, return `-result.points[own_seat.index()]` as the value (lower residual = better; closer gets the bonus baked into points already).
- `BaselineAgent::Search(Box<SearchPlayer>)` with a `BaselineAgent::search(seed, samples)` constructor.
- CLI: `conga-cli eval --a search --b greedy --samples 50 --games 100 --seed 1` works. `conga-cli play --ai search --samples 20` routes seat 1 to the search agent.

**Tests**:
- Unit: `SearchPlayer::act` with K=1 on a hand-crafted obs/legal returns an action from the legal list.
- Unit: Reproducibility: two `SearchPlayer` instances with the same seed, fed the same event + obs sequence, return the same actions.
- Unit: Showdown fallback: construct an obs with `phase == Showdown`, legal with multiple options, assert the returned action matches `GreedyPlayer`'s pick.
- Smoke (#[ignore]d, release): one `run_match(StandardConga, SearchPlayer{samples=20}, GreedyPlayer, dealer=1, seed=1)` finishes and logs `rollouts_per_decision × decisions / duration` as rollouts/sec.

### Slice 4 - Rule-based v2 using the belief tracker (conditional ship)

**Content**:
- `RuleBasedPlayer { greedy: GreedyPlayer, belief: BeliefTracker }`.
- `notify(event)` forwards to `belief.notify(event)`.
- `act(obs, legal)`:
  - Compute `greedy_action = self.greedy.act(obs, legal)`.
  - If it's not a `Discard`, return it.
  - Collect `candidates: Vec<Card>` = all `Discard(c)` actions in `legal` with the same unmatched-rank as greedy's pick (same tiebreak set as D28).
  - If `candidates.len() <= 1`, return `greedy_action`.
  - Score each candidate: `risk(card) = sum over opponent seats of (10 if belief.known_held(seat) extends a visible meld via card, else 0) + (5 × belief.prob_holds(partner_card, seat) for each partner card that forms a Set or Run with `card` on `obs.melds_on_table` or in `belief.known_held(seat)`)`. Return the min-risk candidate (ties break by card index for determinism).
- The exact `risk` function is tuned during the slice. Three seed smokes (200 games/seed vs greedy, same seeds used in m3) at the end of the slice determine ship-or-revert:
  - If `rule_based_v2 vs greedy` win rate ≥ 55% across all three seeds **and** overall Wilson LB (1000 paired deals) > 0.5: ship.
  - Otherwise: revert the slice entirely and report. m4 continues with the existing rule-based agent.
- The slice commit lives on `m4-belief-search`. If reverted, the revert is itself a commit.

**Tests**:
- Unit: existing rule-based tests updated for the new belief-based risk (behaviour is deterministic given the seeded belief state).
- Unit: `notify` forwards every relevant event to the belief tracker (regression that we didn't drop any tracked event).
- Smoke (#[ignore]d): three seeds × 200 games `rule_based_v2 vs greedy` must each report ≥ 55% v2 win rate.
