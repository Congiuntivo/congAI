# Milestone 1: core engine

## Context

Session 0 is accepted (`setup-accepted` on main) and the six showdown details are confirmed (D8–D13). The empty workspace now needs the actual engine: shared types, the meld solver, a `RuleSet` trait, the `StandardConga` implementation of your variant (playing phase, showdown, scoring with the minus-10 and minus-50 bonuses, elimination above 100), `Chance` and the event log with exact replay, conformance tests generic over any `RuleSet`, and a debug CLI that plays one hand with all hands visible so you can verify the rules by hand before any TUI exists.

Exit test: the conformance tests pass on a large batch of random games, a logged game replays to identical states, and you play several hands via the debug command and agree with every legal move and every score.

Nothing in milestone 1 needs network, AI, protocol, server, TUI or Python.

## Known facts I rely on

From `docs/design.md`:
- `RuleSet` trait signature: `new_hand`, `legal_actions`, `apply`, `observe`, `hand_result`, `match_status`, `evaluate_hand`, `sample_state`, plus `id`, `deck`, `seats`.
- `Chance` supplies every shuffle; random during play, reads the log during replay.
- Cards are small integers, hands are 64-bit masks.
- Action space is typed (`Action` enum). The fixed 333-index encoding required for the policy net is deferred to milestone 7.
- Scoring can go negative. Match status is "out above 100, exactly 100 stays in".
- Conformance tests 1–4 are in scope. Test 5 (sampled states reproduce the observation they came from) depends on `sample_state` and is deferred to milestone 4.

From `docs/decisions.md`:
- D2 Rust for the engine. D4 rules pluggable through `RuleSet`. D5 small slices with stop points. D6 branch per milestone.
- D8–D13: all six showdown details confirmed exactly as proposed.

## Debug CLI QOL features (slice 9)

On top of the numbered-menu baseline:

- ANSI colour: red for hearts and diamonds, default for clubs and spades. Degrades cleanly if stdout is not a TTY.
- Hand display grouped by the meld solver's output: the best split shown as `[7H 7D 7C] [5S 6S 7S 8S] | 3C(3)` with `|` separating unmatched cards and their point values in parentheses. `can_close` flag printed next to the hand.
- Every turn echoes seed, turn number, current seat, phase.
- A short action log (last 10 events) printed under the state. `l` at the prompt prints the full log.
- Prompt line: `[1..N] action  |  l=log  s=state-json  q=quit`. `s` dumps the full `State` and the current `Observation` per seat (internal Debug printer, no serde). `q` prints the seed and the actions so far before exiting.
- Menu entries carry notation so you can read them (`3. Discard 7C`), but you type the number.

If any of these grows complex I stop and bring the trade-off; the baseline stays the numbered menu.

### Slice 1 — Cards, hands and seats in `conga-core`

**Files**: `crates/conga-core/src/{lib.rs, card.rs, hand.rs, seat.rs, deck.rs}`

**Content**:
- `Suit` enum (4 variants), `Rank` as a `u8` newtype 1..=10.
- `Card(u8)`: 0..=39 for the variant, with `fn new(suit, rank) -> Card`, `fn suit()`, `fn rank()`, `Display` as `7C`, `10H`, ...
- `DeckSpec { cards: u8 }` and `fn standard_40() -> DeckSpec`.
- `Hand(u64)` with `insert/remove/contains/iter/len/is_empty/union/intersection/difference` and `From<&[Card]>`.
- `Seat(u8)` newtype, `fn next(self, count: u8) -> Seat` for rotation.

**Tests** (all written out by hand):
- `Card::new(Hearts, 7).rank() == 7` and friends; round-trip through index.
- `Hand` contains the right cards after insert/remove; `len` matches `iter().count()`.
- Bitmask ops are symmetric.

**Try it**: not runnable yet (no binary change). `cargo test -p conga-core`.

**Dependencies added**: none.

### Slice 2 — Meld solver in `conga-core`

**Files**: `crates/conga-core/src/meld.rs` (new), small additions to `card.rs`.

**Content**:
- `MeldKind { Set, Run }`.
- `Meld { kind, cards: Hand }` with validity check.
- `MeldParams` (min set size 3, min run size 3, no wrap at 10, each card in one meld).
- `HandEval { splits: Vec<Meld>, unmatched: Hand, unmatched_total: u32, can_close: bool, improvers: Hand }`.
- `fn evaluate_hand(hand: Hand, params: &MeldParams) -> HandEval`. For 7 or 8 cards, exact enumeration.

**Tests** (each hand written out by hand from the design-doc rows):
- 7-card run in one suit → `can_close = true`.
- Meld of 3 + meld of 4, 0 unmatched → `can_close = true`.
- Two melds of 3 + one card value 1..5 → `can_close = true`.
- Two melds of 3 + one card value 6..10 → `can_close = false`.
- One 5-card run + two cards summing to ≤5 → `can_close = true`.
- Zero melds, 7 scattered cards → `can_close = false`, unmatched_total = sum of values.

**Dependencies added**: none.

### Slice 3 — Action, Event, Observation, Phase, HandResult types

**Files**: `crates/conga-core/src/{action.rs, event.rs, observation.rs, phase.rs}`

**Content**:
- `Phase { Draw, Discard, Showdown, Ended }`.
- `Action` enum: `DrawStock`, `DrawDiscard`, `Discard(Card)`, `Close(Card)`, `LayMeld(Meld)`, `AddToMeld { card: Card, meld_index: u8 }`, `Pass`.
- `Event` enum: `Shuffled(Vec<Card>)`, `Dealt { seat, hand_size }`, `Drew { seat, source }`, `Discarded { seat, card }`, `Closed { seat, card }`, `LaidMeld { seat, meld }`, `AddedToMeld { seat, card, meld_index }`, `Passed { seat }`, `HandEnded(HandResult)`.
- `HandResult { points: Vec<i32>, closer: Option<Seat>, bonus: Option<Bonus> }` with `Bonus { MinusTen, MinusFifty }`.
- `Observation { own_seat, current_seat, phase, own_hand: Hand, top_discard: Option<Card>, discard_history: Vec<Card>, stock_size: u8, melds_on_table: Vec<Meld>, scores: Vec<i32>, opponent_hand_sizes: Vec<u8> }`.

**Tests**: construction, equality, Debug round-trip for the variants used in later snapshots.

**Dependencies added**: none.

### Slice 5 — `StandardConga` playing phase in `conga-rules`

**Files**: `crates/conga-rules/src/{lib.rs, standard.rs, state.rs, scoring.rs}`

**Content**:
- `StandardConga` with your variant's parameters (deck 40, seats 2..=4, closing sum 5, max unmatched 2, first-turn close forbidden, empty-stock reshuffle, 100-point elimination).
- `State { hands, stock, discard_pile, scores, dealer, current_seat, phase, melds_on_table, first_turn_done, log_shuffles }`.
- `new_hand`: shuffle via `Chance`, deal 7 per seat, place one card as the starting discard.
- `legal_actions` for Draw and Discard phases:
  - Draw: `DrawStock`, `DrawDiscard` if top discard is present.
  - Discard: `Discard(c)` for each hand card except the one just taken from the discard (confirmed rule 6). `Close(c)` for each card whose removal leaves a split with `can_close = true`, except on this seat's first turn (confirmed rule 5 + first-turn rule).
- `apply`: draws, discards, close (sets phase to Showdown), empty-stock reshuffle (confirmed rule 14), event emission, first-turn flip.
- `observe`: seat-relative observation.
- `evaluate_hand`: delegates to the meld solver.
- `hand_result`: `None` while phase != Ended.
- Activate conformance tests 1 and 2 (cards accounted for; no hidden card in any observation) with a random policy that never closes. Test 3 (always a legal action) and test 4 (replay) wait for later slices.

**Dependencies added**: `rand_chacha` and `proptest` (dev-dep).

**Tests**:
- Deal 2-, 3-, 4-player hands, invariants hold.
- Empty-stock reshuffle keeps the top discard aside.
- First-turn close is illegal; second-turn close is legal when the hand allows it.
- `Discard(c)` where `c` was just drawn from the top discard is not in `legal_actions`.

### Slice 6 — Showdown phase in `conga-rules`

**Files**: additions to `standard.rs`, new `showdown.rs`.

**Content**:
- Phase Showdown entered via `Close(c)`. Starting with the closer, each seat takes a turn in rotation.
- Showdown legal actions: `LayMeld(m)` valid from the acting seat's hand, `AddToMeld { card, meld_index }` extending a tabled meld under the meld rules, `Pass`.
- Showdown ends when a full round passes with no card placed (detail (d) kept-in-hand is allowed).
- Detail (c): the closer's first showdown turn must lay a split that meets the closing condition. `legal_actions` in that first turn only includes moves that are part of such a reducing sequence; `Pass` is illegal for the closer's first turn. I will stop and bring the trade-off if the enumeration grows ugly.
- Detail (a): the closer can keep adding to other players' melds in later rounds.
- Detail (f): hands stay hidden; no change to `observe` since own-hand is already the only hand a seat can see.

Activate conformance test 3 (always a legal action while a hand runs).

**Tests**:
- Showdown ends after a round of all-Pass.
- Closer must lay the closing split before anyone else moves.
- A non-closer who empties their hand does not get a bonus (detail (e)).
- A player keeps a meld in hand → it counts as points (detail (d)).

### Slice 7 — Scoring, bonuses, elimination, match status

**Files**: `scoring.rs`, `standard.rs` updates.

**Content**:
- `hand_result` at end of showdown: each seat's points = sum of card values remaining in hand.
- Closer with 0 unmatched at the moment of closing: minus 10 (detail (b)+(e)).
- Closer with a 7-card run in one suit: minus 50 (confirmed rule 11, detail (e)).
- `match_status`: any seat with score > 100 is out; if one seat remains, `Winner`; if all remaining seats go out together, lowest score wins (confirmed rule 16).

**Tests**:
- Hand-written closes: 7-card run → closer -50, others pay their hands.
- 0-unmatched close: closer -10, others pay their hands.
- Match status: three seats above 100 triggers rule-16 tie-break.

### Slice 8 — Event log, `Chance` impls, exact replay

**Files**: `crates/conga-core/src/{chance.rs, log.rs}`, `crates/conga-rules/` wiring.

**Content**:
- `RandomChance(ChaCha8Rng)` and `ReplayChance { shuffles: VecDeque<Vec<Card>> }`.
- `GameLog { ruleset_id: RuleSetId, seats: u8, dealer: Seat, actions: Vec<Action>, shuffles: Vec<Vec<Card>> }`.
- `fn replay<R: RuleSet>(rules: &R, log: &GameLog) -> Vec<R::State>` rebuilds the state sequence.
- Property test: 10,000 random games with `RandomChance`, log each, replay with `ReplayChance`, assert state equality after every action. Activates conformance test 4 and the milestone exit condition.

**Tests**: the proptest above, plus a hand-written 2-player log replayed step by step with assertions at each state.

### Slice 9 — Debug command in `conga-cli`

**Files**: `crates/conga-cli/src/{main.rs, debug_hand.rs}`.

**Content**:
- `conga-cli debug-hand --seed <u64> --players <2|3|4>`.
- Clap derive API, one subcommand.
- Prints: scores, each seat's hand (all visible, this is the debug tool), top discard, stock size, melds on table, phase, current seat.
- Numbered list of legal actions + stdin loop. Plus the QOL features listed above.
- Loop ends when the hand ends; prints `HandResult`.

**Tests**: an in-process test with a canned stdin buffer: play a scripted 2-player hand, assert the printed `HandResult`.

**Try it (end-to-end, by hand)**: `cargo run -p conga-cli -- debug-hand --seed 42 --players 2`.
